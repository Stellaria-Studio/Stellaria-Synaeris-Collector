# Collector data format

Each sealed Episode contains `visual.mkv`, `manifest.json`, frame-to-video timing, and typed Parquet event streams for input, OCR, UI, pose, tools, observations and performance. All event timestamps are Episode-relative QPC nanoseconds and carry a sequence number. The manifest records capture configuration, availability and provenance. Incomplete, synthetic, unfocused or otherwise unqualified observations remain explicit.

`capture_streams.version=1` adds per-source recording status to the existing Episode manifest. `video`, `input`, `telemetry`, `performance` and `ocr` each record `requested`, `started`, `status` and `reason`. `disabled` means an operator-disabled source, `not_started` means it has not started, `enabled` means its startup returned, and `unavailable` records the applicable preflight or runtime reason. An enabled producer can still have missing observations. Operator choices capture the requested scope. Research authorization is external.

The Episode schema and existing files remain in place. Disabled streams can have empty Parquet files. Disabled local input also closes telemetry ingress for dispatch rows, and disabled OCR closes telemetry ingress for OCR rows. When the telemetry listener is disabled, its UI and pose observations are omitted. Local input keeps a null `bgi_tool_active` when the bridge is absent. Frame time and focus remain available in Video-only. Earlier manifests without this block remain readable.

After sealing, `auto_index.json`/`.html` contain weak scene and text candidates. `decision_units.v1.jsonl` and its `.audit.json` are recomputable sidecars. Each variable-duration unit records `Goal → World State → Affordance → Intent → Expected Effect → Action → Observed Effect → Progress → Outcome`, with per-field status, source evidence and training weight. Source video, frame map, input, index and manifest hashes bind the sidecar to the mother recording. When input was disabled or unavailable, recorded-input counts and held-state summaries are null, and the index suppresses quiet-input inference. Source status distinguishes this case from an observed empty window.

Automatic OCR and scene scores are not calibrated probabilities. Physical OS hook events do not establish that the game received an input. Historical Raw Input mouse packets do not establish their human/BGI producer. Old video cannot reconstruct an independently verified Intent, Expected Effect or task Outcome. Candidate semantic supervision remains weight zero until reviewed and admitted outside this recorder.

The default local data path is `%LOCALAPPDATA%\Stellaria Synaeris\data\episodes`. The updater uses `%LOCALAPPDATA%\Stellaria Synaeris Collector\updates` and leaves the recording tree untouched.
