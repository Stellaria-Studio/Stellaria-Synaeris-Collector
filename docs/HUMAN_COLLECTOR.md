# 人工采集说明

当前版本：`0.6.0`。从本仓库的 GitHub Releases 下载 ZIP，解压完整目录，**直接双击 `SynaerisCollector.exe`**。如果原神以管理员权限运行，Windows 会正常显示 UAC 确认；完成确认后不需要启动脚本。

1. 打开原神，进入要记录的区域。
2. 打开采集器，保持默认“自由采集”，点 **开始采集**。界面收起后正常游玩。
3. 点 **停止并保存** 或按 F10。程序自动封存录像、整理候选场景与任务文字、编译决策单元，并完整解码校验。

无需边玩边标注。F6–F9 备注是可选的。OCR、场景、Goal 等自动结果均为候选，未自动证实意图、战斗/解谜成功或游戏动作回执。录像、同步事件和候选旁路文件默认保存在 `%LOCALAPPDATA%\Stellaria Synaeris\data\episodes`，不会上传到 GitHub。

采集器在后台检查公开 GitHub Release。新版本会先下载并验证到当前用户目录，**下次打开原来的 EXE 时自动运行新版**。下载不会中断正在录制的 Episode；断网时继续使用当前版本。GitHub Release 的 ZIP 和完整 `_internal` 目录必须保留，不能只单独复制 EXE。

采集软件可以收起，游戏需要保持前台才能得到合格的动作记录。数据菜单可打开最近录像、重新整理旧 Episode 与查看日志；高级参数放在设置菜单，团队默认参数保持统一。
